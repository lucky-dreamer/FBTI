# FBTI (Football TI) — 微信小程序技术设计文档

## 1. 项目概述

FBTI（Football TI）是一个基于微信小程序 + 微信云开发的趣味人格测试工具。它将经典的 MBTI 人格测试以足球场景重新包装，用户完成 32 道题后得到自己的"足球人格类型"，并匹配 16 位世界杯热门球星中的一位。

### 核心数据

| 项目 | 值 |
|------|-----|
| 题目数 | 32 题（每维度 8 题） |
| 人格类型 | 16 种 MBTI |
| 匹配球星 | 16 位 |
| 前端框架 | 原生微信小程序 |
| 后端 | 微信云开发（云数据库 + 云函数 + 云存储） |
| 目标用户 | 泛足球爱好者 / 普通用户 |

## 3. 页面设计

### 3.1 首页（index）

| 元素 | 说明 |
|------|------|
| 标题 | "FBTI·足球人格测试" |
| 副标题 | "MBTI已经过时，FBTI（FOOT BALL TI）来啦^_^!" |
| 视觉效果 | 动态绿茵草皮背景 + 弹跳足球动画 |
| 社交证明 | "已有 XX 人测过" 实时计数 |
| 核心按钮 | "⚽ 开始测试" 大按钮 |
| 底部 | 简要说明（32题/3分钟/16球星） |

### 3.2 答题页（quiz）

- 每题一个全屏页面，顶部为进度条
- 进度条仿足球比赛：**上半场**(1-16题) → **中场休息动画** → **下半场**(17-32题) → **伤停补时**(最后5题特殊效果)
- 每题中间展示题目文字，下方两个大按钮（A/B选项）
- 按钮有足球风格设计 + 点击触感反馈
- 题目内容：足球场景化、轻松有趣、人人都能参与
- **每题结束**：轻量过渡动画到下一题
- **中场休息**：展示一句足球金句 + 进度半程提示

### 3.3 结果页（result）

- 开场：卡片翻牌动画，显示匹配球星
- 展示内容：
  - 球星姓名 + 国籍旗帜 + 头像
  - MBTI 人格类型（如 ISFP）
  - 人格称号（如"球场艺术家"）
  - 匹配度百分比（动态增长动画）
  - 人格描述文案
  - 球星金句
- 底部操作：
  - "分享好友" — 生成分享卡片
  - "保存海报" — 保存图片到相册
  - "重新测试"
  - "查看全部球星"
- 视觉效果：烟花/礼花粒子动画 + 球星卡炫酷背景

## 5. 题目设计框架

### 5.1 四维度 → 足球化表达

| MBTI 维度 | 足球化概念 | 题数 |
|-----------|-----------|------|
| **E / I**（外向/内向） | 庆祝方式 / 场外生活选择 | 8 题 |
| **S / N**（实感/直觉） | 球场决策方式 / 训练态度 | 8 题 |
| **T / F**（思考/情感） | 对待队友 / 输赢心态 | 8 题 |
| **J / P**（判断/感知） | 比赛准备 / 生活方式 | 8 题 |

### 5.2 题目示例

**E/I 维度示例：**

1. 球队刚赢下一场关键比赛，你的第一反应：
   - A. 冲去和队友们疯狂庆祝，发IG快拍 🔥 (E)
   - B. 安静地坐在更衣室回味，享受自己的时刻 🤔 (I)

2. 周末休息日你更想做什么：
   - A. 拉上兄弟们去踢野球，顺便撸串 🍖 (E)
   - B. 一个人在家看比赛录像，研究战术 📺 (I)

**S/N 维度示例：**

3. 教练让你主罚关键任意球，你满脑子想的是：
   - A. 人墙位置、门将习惯、风速、草坪湿度 (S)
   - B. 一个从未见过的诡异弧线，让全场目瞪口呆 (N)

4. 看到对手的新阵型，你第一反应：
   - A. 他们的阵型有什么破绽？哪个区域空虚？ (S)
   - B. 如果我是教练，我会用一套完全不同的体系来破解 (N)

**T/F 维度示例：**

5. 队友连续错过你传的绝妙好球：
   - A. 直接告诉他"那球你得提前跑位，慢了半秒" (T)
   - B. 拍拍他肩膀"没事，下次我传舒服点" (F)

6. 点球大战最后一个主罚，压力山大：
   - A. 冷静计算门将扑点习惯，选最稳的角度 (T)
   - B. 闭上眼睛，深呼吸，相信自己的直觉 (F)

**J/P 维度示例：**

7. 比赛前一天的准备工作：
   - A. 严格按计划：几点吃饭、几点热身、几点冥想 (J)
   - B. 随缘准备，甚至会即兴加练几个新花活 (P)

8. 你的球衣号码选择标准：
   - A. 固定一个幸运号码，从不改变 (J)
   - B. 每年换一个号码，看心情 (P)

（每题均配足球表情符号和彩蛋金句，全部 32 题在实施时完整定义）

## 7. 云函数设计

### 7.1 calculateResult

- 触发器：用户提交 32 题答案
- 输入：`{ answers: ["A","B","A",...], openid: "xxx" }`
- 处理逻辑：
  1. 遍历 32 题答案，按 dimension 分组计分
  2. 每个维度分数高者胜出：
     - E≥I → E，否则 I
     - S≥N → S，否则 N
     - T≥F → T，否则 F
     - J≥P → J，否则 P
  3. 拼合 4 字母得到 MBTI 类型
  4. 查 stars 集合匹配对应球星
  5. 计算匹配度 = (各维度胜出分数百分比加权平均)
  6. 写入 records 集合
- 输出：`{ type: "ISFP", star: { ... }, matchRate: 92 }`

### 7.2 getStars

- 触发器：查看球星列表/详情
- 输入：`{ type: "ISFP" }` 可选
- 输出：球星列表或详情
